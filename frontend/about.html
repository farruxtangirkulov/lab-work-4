About This Lab (loaded inside a frame)

This document is displayed inside the <iframe> element of index.html — proving that one HTML page can embed another page.

The website has three parts:

  • Page 1 (Frame): the home page embeds this page using an iframe.
  • Page 2 (Form): data goes to PHP (submit.php), which saves it.
  • Page 3 (Table): data comes back from PHP (get_students.php) with CSS styling.
